**SQL** (Structured Query Language) হলো database-এর সাথে কথা বলার ভাষা। দোকানের হিসাব, স্কুলের রেজাল্ট, ব্যাংকের লেনদেন, সব জায়গায় ডেটা থাকে database-এ, আর সেখান থেকে কিছু বের করতে, যোগ করতে বা বদলাতে লাগে SQL।

এই সাইটের সব query চলে আসল **SQLite**-এ, আপনার browser-এর ভেতরে। কিছু install করতে হয় না, আর এখানে যা-ই বদলান, আসল কোথাও কিছু হয় না।

## table, row আর column

database-এ ডেটা থাকে **table**-এ, অনেকটা Excel-এর sheet-এর মতো:

- **column**: খাড়া ঘর, প্রতিটার একটা নাম আর ধরন থাকে, যেমন `name` (লেখা) বা `price` (সংখ্যা)।
- **row**: আড়াআড়ি এক সারি, মানে একটা জিনিসের পুরো তথ্য, যেমন একটা পণ্য।

এই সাইটের পাঠগুলোয় একটা ছোট **অনলাইন দোকান**-এর ডেটা আছে:

| table | কী আছে |
| --- | --- |
| `districts` | জেলার নাম আর বিভাগ |
| `customers` | গ্রাহকের নাম, ফোন, জেলা (`district_id`), যোগ দেওয়ার তারিখ |
| `products` | পণ্যের নাম, ধরন (`category`), দাম, স্টক |
| `orders` | কোন গ্রাহক (`customer_id`) কবে অর্ডার দিল, অবস্থা (`status`), কীভাবে টাকা দিল (`payment`) |
| `order_items` | কোন অর্ডারে কোন পণ্য কয়টা, কত দামে |

## প্রথম query

নিচের বাক্সে একটা query আগে থেকেই লেখা আছে, আর পেজ খোলার সময় একবার চলেও গেছে। এর মানে: "`districts` table-এর সব column, সব row দেখাও"।

```sql
SELECT * FROM districts;
```

এবার বাক্সে `districts`-এর জায়গায় `products` লিখে **রান করুন** চাপুন (বা Ctrl + Enter)। গোলমাল হলে **মূল query-তে ফিরুন** চাপলেই আগের অবস্থায় ফিরবে। আর **ধাপে ধাপে রান করুন** চাপলে দেখবেন SQLite ভেতরে কোন ক্রমে কাজটা করে।

## কয়েকটা নিয়ম, শুরুতেই

- SQL-এর শব্দ (`SELECT`, `FROM`) বড় বা ছোট হাতের যেকোনোভাবে লেখা যায়। `select * from districts` একই কাজ করে। চোখে পড়ার জন্য সাধারণত বড় হাতে লেখা হয়।
- query-র শেষে `;` দিলে বোঝায় এখানে query শেষ। একটাই query হলে না দিলেও চলে, কয়েকটা হলে লাগে।
- লেখা (text) দিতে হয় একক উদ্ধৃতিতে: `'ঢাকা'`। সংখ্যা উদ্ধৃতি ছাড়া: `1000`।
- এক query কয়েক লাইনে ভেঙে লেখা যায়, SQLite লাইন ভাঙা নিয়ে মাথা ঘামায় না।

```sql
SELECT name, division
FROM districts;
```

প্রতিটা পাঠ নিজে নিজে সম্পূর্ণ, তাই যেটা দরকার সেটা সরাসরি খুলতে পারেন। শুরু থেকে শিখতে চাইলে পরের পাঠ [SELECT](/learn/select/)।
