query-র ভেতরে ছোট ছোট হিসাব আর তুলনা লাগে সবসময়। SQL-এর চিহ্নগুলো প্রায় অঙ্কের মতোই, কয়েকটা জায়গায় একটু আলাদা।

## অঙ্কের হিসাব

| চিহ্ন | কাজ | উদাহরণ |
| --- | --- | --- |
| `+` | যোগ | `price + 50` |
| `-` | বিয়োগ | `price - 100` |
| `*` | গুণ | `price * stock` |
| `/` | ভাগ | `price / 2` |
| `%` | ভাগশেষ | `id % 2` |

```sql
SELECT name, price, price * 0.9, price - 100
FROM products;
```

দ্বিতীয় হিসাবটা ১০% ছাড়ের দাম, তৃতীয়টা ১০০ টাকা কম।

## পূর্ণসংখ্যার ভাগে সাবধান

SQLite-এ দুইটা পূর্ণসংখ্যা ভাগ করলে ফলও পূর্ণসংখ্যা, দশমিক অংশ ফেলে দেয়। দশমিক চাইলে অন্তত একটা সংখ্যা দশমিকে লিখুন:

```sql
SELECT 7 / 2, 7 / 2.0, 7 % 2;
```

`7 / 2` দিল `3`, আর `7 / 2.0` দিল `3.5`। গড় বা শতাংশ হিসাবের সময় এই ভুলটা খুব হয়।

## তুলনা

| চিহ্ন | মানে |
| --- | --- |
| `=` বা `==` | সমান |
| `<>` বা `!=` | সমান নয় |
| `>`, `<`, `>=`, `<=` | বড়, ছোট, বড় বা সমান, ছোট বা সমান |

তুলনার ফল হয় `1` (সত্য) বা `0` (মিথ্যা)। `WHERE` আসলে এই ফলটাই দেখে:

```sql
SELECT name, price, price > 1000
FROM products;
```

`WHERE`-এ শর্তের দুই পাশেই হিসাব থাকতে পারে। যেসব পণ্যের স্টকের মোট দাম ৩০,০০০ টাকার বেশি:

```sql
SELECT name, price, stock
FROM products
WHERE price * stock > 30000;
```

## লেখা জোড়া: `||`

দুই টুকরো লেখা জুড়তে `||` (অনেক ভাষায় এটা "অথবা", SQL-এ নয়!):

```sql
SELECT name || ' (' || division || ' বিভাগ)'
FROM districts;
```

## নিজে চেষ্টা করুন

প্রতিটা পণ্যের নাম আর ১৫% ভ্যাটসহ দাম দেখুন (দাম × ১.১৫)।

```sql
SELECT name, price FROM products;
```
